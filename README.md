# Sistema de Gestión de Cursos UTC 3.0

- Java
- Programación Orientada a Objetos
- ArrayList
- Árbol binario de búsqueda

- Inserción directa
- Selección directa
- Búsqueda secuencial
- Búsqueda binaria
